# AI Dental Concierge — Demo (Next.js + TypeScript)

A working 24/7 AI front-desk chat widget: answers patient questions, books appointments,
and never gives clinical advice (routes to staff). Built to demo to real practices.

## Run it
```bash
npm install
npm run dev     # http://localhost:3000
```
The widget works IMMEDIATELY with no setup (keyword demo-mode fallback).

## Turn on real AI (optional)
Create `.env.local`:
```
GEMINI_API_KEY=xxxxx
```
Now replies are generated by Gemini using the practice info in `lib/practice.ts`.
(You can swap in another provider by editing `app/api/chat/route.ts`.)

## Make it a bot for a REAL client
1. Open `lib/practice.ts` and replace the `practice` object with their real
   name, hours, services, prices, insurance. That's it — the whole bot updates.
2. Bookings hit `app/api/booking/route.ts` — swap the in-memory store for your
   DB, their scheduler, your CRM, or an email/webhook.

## The demo money-shot
Open the page, type: **"How much are braces and can I come Saturday?"**
→ it answers from the practice info → invites booking → opens the form →
captures the lead → shows confirmation. That 30-second flow is your sales demo.

## Files that matter
- `lib/practice.ts` — the bot's knowledge + system prompt (edit per client)
- `app/api/chat/route.ts` — chat endpoint (AI + no-key fallback)
- `app/api/booking/route.ts` — booking capture
- `components/ChatWidget.tsx` — the widget UI + booking form
- `app/page.tsx` — a fake practice site so the demo looks real
